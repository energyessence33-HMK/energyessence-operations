# Energy Essence Operations

Central hub for workflow automation, integrations, and operational management.

## 📁 Directory Structure

- **workflows/** - GitHub Actions workflows for CI/CD automation
- **webhooks/** - Webhook handlers and event listeners
- **zapier/** - Zapier integration configs and tasks
- **logs/** - Operational logs and monitoring data
- **scripts/** - Utility scripts for maintenance and deployment

## 🚀 Quick Start

1. Clone this repository
2. Review existing workflows in `workflows/`
3. Configure webhooks in `webhooks/` directory
4. Set up Zapier integrations via `zapier/` configs
